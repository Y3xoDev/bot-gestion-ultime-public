# Contribuer

Les corrections et améliorations ciblées sont bienvenues.

1. Crée une branche depuis `main`.
2. N'ajoute jamais de `.env`, token, donnée de serveur, transcript ou fichier de stockage.
3. Exécute `npm ci`, `npm run check` et `npm test`.
4. Décris le comportement modifié, les vérifications réalisées et les éventuels risques dans la pull request.

Les changements de modération, permissions, tickets, ModMail et AutoMod doivent conserver les contrôles d'autorisation au moment de l'exécution.
